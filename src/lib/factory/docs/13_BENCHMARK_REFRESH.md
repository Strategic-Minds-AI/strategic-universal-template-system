# BENCHMARK REFRESH SYSTEM

The registry should be refreshable without destabilizing active projects.

## Refresh workflow
1. Research current high-quality product patterns and official platform guidance.
2. Add candidate patterns to a staging registry, never directly to canonical.
3. Normalize candidates into existing taxonomy.
4. Deduplicate by interaction purpose, not visual novelty.
5. Run compatibility, accessibility, responsive, and regression tests.
6. Promote only validated additions under a new registry version.
7. Existing projects remain pinned to their original registry version unless explicitly upgraded.

## Evidence sources
Prefer official platform design guidance, accessibility standards, established design-system specifications, and real production interfaces. Trend signals may influence candidate exploration but cannot override usability/accessibility gates.
