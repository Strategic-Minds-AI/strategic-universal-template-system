# UNIVERSAL FRONTEND FACTORY — BASE44 v2

A deterministic frontend design/compiler system for mobile apps, PWAs, desktop applications, dashboards, ecommerce, marketplaces, directories, portals, marketing sites, and AI workspaces.

## What changed from v1
v1 established a broad reusable pattern registry. v2 adds the quality controls needed to make outputs materially more consistent and less generic:

- semantic color generation instead of static palette-only selection
- DTCG 2025.10-compatible token exports
- light/dark/high-contrast theme contracts
- domain packs + experience recipes + platform adapters
- multi-pass Design Quality Compiler
- consistency linting and generic-AI UI guardrails
- visual regression baselines
- independent validator + targeted repair loop
- version-pinned recommendation learning without silent registry mutation

## Core rule
**Structure is selected before style. Meaning is tokenized before components are decorated. Validation is independent before anything is accepted.**
