# DESIGN QUALITY COMPILER

Generation is a series of deterministic passes, not one prompt.

## Pass 1 — Intent contract
Lock audience, primary task, platform, business goal, content/data truth, and forbidden claims.

## Pass 2 — Information architecture
Choose domain pack, experience recipe, route map, object model, and navigation.

## Pass 3 — Flow graph
Attach canonical flows and edge states before visual styling.

## Pass 4 — Layout skeleton
Compose content hierarchy, grid, density, and responsive transformations in grayscale/wireframe form.

## Pass 5 — Token synthesis
Generate semantic color, typography, spacing, shape, elevation, motion, icon, and imagery tokens.

## Pass 6 — Component composition
Instantiate only registry components compatible with the recipe and platform adapter.

## Pass 7 — Content hierarchy
Apply copy density, proof, action hierarchy, empty/error content, and data display rules.

## Pass 8 — Responsive/state completion
Generate every validation viewport and required state matrix.

## Pass 9 — Visual polish
Apply imagery, surface system, motion, micro-interactions, and focal accents without changing the frozen UX skeleton.

## Pass 10 — Independent validation
A distinct validator checks token purity, coherence, accessibility, overflow, state coverage, reference parity, and platform conventions.

## Pass 11 — Targeted repair
Repair only listed deltas. No unrelated redesign. Maximum five automatic rounds.

## Pass 12 — Freeze/export
Hash BuildSpec, selected pattern IDs, registry version, token graph, screen contracts, screenshots, and validation receipt.

### Fail-closed rule
No aggregate aesthetic score can override a failed hard gate. Accessibility, overflow, missing states, broken navigation, token drift, or unauthorized Reference Lock variance blocks PASS.
